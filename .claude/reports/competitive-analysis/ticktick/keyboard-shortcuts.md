# TickTick — Atalhos de Teclado Completos
**Data:** 2026-05-04 | **Pesquisa:** Claude Code (Sonnet 4.6)

> Fontes: [quickref.me/ticktick](https://quickref.me/ticktick.html), [usethekeyboard.com/ticktick](https://usethekeyboard.com/ticktick/), [help.ticktick.com — Desktop Shortcuts](https://help.ticktick.com/articles/7055780449171275776), [tutorialtactic.com](https://tutorialtactic.com/blog/ticktick-shortcuts/), [hotkeyguru.com](https://hotkeyguru.com/ticktick-hotkeys/)

> Itens `[a confirmar]` foram encontrados em fontes de terceiros e não verificados na documentação oficial.

## DESKTOP — Geral

| Atalho (Win) | Atalho (Mac) | Ação |
|-------------|-------------|------|
| `Ctrl+Shift+A` | `Cmd+Shift+A` | Quick Add — barra de adição rápida global (sem abrir o app) |
| `Ctrl+Shift+L` | `Cmd+Shift+L` | Mostrar/ocultar mini window flutuante |
| `Ctrl+N` | `Cmd+N` | Nova tarefa |
| `Ctrl+S` | `Cmd+S` | Sincronizar tarefas |
| `Ctrl+F` | `Cmd+F` | Buscar tarefa |
| `Ctrl+P` | `Cmd+P` | Imprimir |
| `Ctrl+Shift+M` | `Cmd+Shift+M` | Completar tarefa selecionada |
| `Ctrl+Shift+P` | `Cmd+Shift+P` | Iniciar ou abandonar Pomodoro na tarefa selecionada |

## DESKTOP — Datas da Tarefa

| Atalho (Win) | Atalho (Mac) | Ação |
|-------------|-------------|------|
| `Ctrl+D` | `Cmd+D` | Abrir seletor de data |
| `Ctrl+0` | `Cmd+0` | Limpar data (remover due date) |
| `Ctrl+1` | `Cmd+1` | Definir due date = Hoje |
| `Ctrl+2` | `Cmd+2` | Definir due date = Amanhã |
| `Ctrl+3` | `Cmd+3` | Definir due date = Próxima semana |

> **Conflito de atalho:** `Ctrl+0` também é listado em algumas fontes como "No Priority". Isso pode depender do contexto (campo de data vs. campo de prioridade com foco). `[a confirmar]`

## MOBILE (iOS e Android)

> Os atalhos de teclado físico no mobile dependem de teclado bluetooth conectado e variam por plataforma. As ações abaixo são gestuais, não atalhos de teclado.

| Gesto | Ação |
|-------|------|
| Arrastar botão `+` | Quick add em posição específica da lista (inclusive como subtarefa) |
| Long press no tempo de tarefa | Abrir Status Bar de progresso (%) |
| Swipe left | Ação customizável (padrão: agendar) |
| Swipe right | Ação customizável (padrão: mover para lista) |
| Toque na data da tarefa | Alterna entre "data" e "dias restantes" (Countdown mode) |
| Toque no número de streak de hábito | Alterna entre "Streak atual" e "Total de dias" |

## WEB APP (app.ticktick.com)

> A web app compartilha a maioria dos atalhos do desktop. Atalhos específicos da web `[a confirmar]`:

| Atalho | Ação |
|--------|------|
| `Ctrl+Shift+A` | Quick add (via browser, sem extensão) |
| `Enter` | Confirmar criação de tarefa em edição inline |
| `Shift+Enter` | Nova linha dentro de descrição de tarefa |
| `Tab` | Indentar subtarefa um nível abaixo |
| `Shift+Tab` | Desindentar subtarefa um nível |

## EDITOR DE DESCRIÇÃO / NOTAS (Markdown)

> Atalhos de formatação Markdown que funcionam no campo de descrição e no módulo Notes:

| Atalho | Ação |
|--------|------|
| `**texto**` | **Negrito** |
| `_texto_` | *Itálico* |
| `~~texto~~` | ~~Tachado~~ |
| `` `código` `` | Código inline |
| `# Título` | H1 |
| `## Título` | H2 |
| `- item` | Lista não ordenada |
| `1. item` | Lista ordenada |
| `- [ ] item` | Checklist (item desmarcado) |
| `- [x] item` | Checklist (item marcado) |
| `[texto](url)` | Link |
| `> texto` | Blockquote |

## GAP CRÍTICO PARA O OXY

O TickTick tem poucos atalhos em comparação com ferramentas como Notion, Linear, ou Things 3. Oportunidades para o Oxy:

1. **Paleta de comandos completa (`Cmd+K`)** — TickTick não tem; Oxy pode implementar uma command palette de nível Linear/Arc
2. **Atalhos customizáveis** — TickTick adicionou isso em 2024, mas de forma limitada
3. **Atalhos por view** (ex: `G+T` para Today, `G+I` para Inbox, estilo Todoist) — TickTick não tem shortcuts de navegação tipo Vim
4. **`/` commands no editor de descrição** — TickTick não implementa; Oxy pode ter vantagem aqui com Plate.js/BlockNote
